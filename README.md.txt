# 🔐 End-to-End Encrypted LAN Chat

A Python-based encrypted messaging system using AES encryption and socket programming.

## Features

- Real-time encrypted LAN chat
- Manual encryption/decryption mode
- AES authenticated encryption
- Multi-client communication

## Installation

```bash
pip install -r requirements.txt
```

## Run Server

```bash
py server.py
```

## Run Client

```bash
py client.py
```
